# MeetPoint WBS 및 역할 분담

## 1. 문서 목적

이 문서는 MeetPoint의 현재 구현 상태를 기준으로 작업을 다시 정렬한 실행 문서이다.

기획, 구조, 기술, API, 화면, 테스트, 배포 문서가 무엇을 만들었는지 설명한다면, 본 문서는 지금 무엇이 완료되었고 무엇이 아직 남아 있는지, 그리고 어떤 역할 범주에서 후속 정리가 필요한지를 한눈에 보이게 하는 것을 목표로 한다.

이 문서는 더 이상 초기 팀 폴더별 UI-only 개발 계획을 유지하지 않는다. 현재 기준으로는 하나의 통합 앱이 존재하며, WBS도 그 기준으로 관리한다.

---

## 2. 문서 범위

포함 범위:

1. 현재 구현 기준 완료 작업 정리
2. 기능 영역별 역할 분담 정리
3. 남은 작업과 문서 정합화 항목 정리
4. 테스트와 배포 준비 상태 정리
5. 제출 직전 점검 기준 정리

제외 범위:

1. WebSocket 기반 실시간 채팅 확장
2. 백그라운드 위치 추적
3. 추천 이력 저장
4. 비밀번호 재설정
5. 관리자용 운영 화면

---

## 3. 운영 원칙

### 3.1 기본 원칙

1. PRD 최신 문서를 구현 기준 문서로 사용한다.
2. WBS는 기능 분업보다 현재 상태와 남은 작업을 분명히 보여 주는 데 집중한다.
3. 하나의 기능이 화면, API, DB, 외부 연동을 함께 갖는 경우 통합 단위로 관리한다.
4. 문서와 실제 구현이 충돌하면 현재 소스와 최신 PRD를 우선 확인한다.
5. Git 작업은 사용자 승인 후에만 각 대상 앱 저장소에서 진행한다.

### 3.2 완료 판단 원칙

아래 조건을 모두 만족하면 완료로 본다.

1. 화면 또는 API가 현재 앱에서 실제로 확인된다.
2. 관련 PRD 문서가 최신 상태로 정리되어 있다.
3. 테스트 체크리스트에서 점검 가능한 기준이 있다.
4. lint, type-check, build 또는 문서 검증 기준에 치명적 오류가 없다.

## 5. 현재 상태 요약

### 5.1 완료된 핵심 기능

1. JWT httpOnly 쿠키 기반 회원가입, 로그인, 로그아웃
2. 보호 페이지와 보호 API 접근 제어
3. 친구 요청, 수락, 거절, 삭제 흐름
4. 댓글형 채팅, unread 상태, 이전 메시지 로드
5. 현재 위치 공유와 저장된 출발 위치 CRUD
6. Kakao 지도 렌더링, 주소 검색, 핀 지정, 추천 지도 표시
7. 지금 만나기 / 나중에 만나기 추천 결과 10개와 요약 표시
8. 모바일 전체화면 지도와 결과 시트 동작
9. Supabase 헬스체크 Route Handler 와 Vercel cron 구성
10. PRD 01~09 최신화

### 5.2 현재 남은 정리 작업

1. WBS 문서 최신화 완료 반영
2. PRD와 engineering 문서 사이 불일치 정리
3. engineering 문서 최신화
4. 최종 제출용 문서와 발표 자료 정리
5. 배포 전 최종 테스트 점검

## 9. 완료 체크포인트

### 9.1 기능 체크

1. 인증과 보호 라우팅이 정상 동작한다.
2. 친구 요청과 채팅 흐름이 끊기지 않는다.
3. 위치 공유와 저장 위치 흐름이 동작한다.
4. 추천 결과, 지도, 길찾기 카드가 함께 갱신된다.
5. 모바일 전체화면 지도 UX가 깨지지 않는다.

### 9.2 문서 체크

1. PRD 01~10이 현재 구현과 일치한다.
2. README가 현재 스크립트와 환경 변수 기준을 반영한다.
3. engineering 문서에 오래된 경로나 UI-only 설명이 남아 있지 않다.
4. 테스트 및 배포 문서가 현재 운영 기준을 반영한다.
