# MeetPoint 테스트 체크리스트

## 1. 문서 목적

이 문서는 MeetPoint MVP 1차 구현이 실제로 동작하는지 확인하기 위한 테스트 체크리스트 문서이다.

기획 문서, 화면 명세서, API 명세서, DB 문서에서 확정한 기준을 실제 테스트 항목으로 다시 풀어서, 구현 완료 후 무엇을 어떤 순서로 확인해야 하는지 명확히 정리하는 것을 목표로 한다.

---

## 2. 범위

본 문서는 아래 범위를 포함한다.

1.  시작 화면 테스트
2.  인증 테스트
3.  친구 기능 테스트
4.  채팅 기능 테스트
5.  위치 공유 테스트
6.  지도 표시 테스트
7.  추천 기능 테스트
8.  오류 및 빈 상태 테스트
9.  배포 전 최종 확인 항목

본 문서의 기본 범위에서 제외하는 항목은 아래와 같다.

1.  WebSocket 기반 실시간 채팅 테스트
2.  실시간 GPS 추적 테스트
3.  비밀번호 재설정 테스트
4.  닉네임 찾기 테스트
5.  추천 이력 저장 테스트

## 3. 테스트 기본 원칙

### 3.1 MVP 기준 우선순위

MeetPoint 테스트는 아래 순서를 기준으로 진행한다.

1.  사용자가 가입 또는 로그인할 수 있는가
2.  친구를 추가하고 선택할 수 있는가
3.  메시지를 저장하고 다시 볼 수 있는가
4.  위치를 저장하고 지도에 표시할 수 있는가
5.  추천 결과를 3개까지 안정적으로 반환할 수 있는가

즉, 테스트는 기능을 개별로 보는 것보다 실제 사용자 흐름이 끝까지 이어지는지를 우선 본다.

### 3.2 테스트 환경 원칙

테스트는 아래 환경 중 최소 1개 이상에서 수행한다.

1.  local 개발 환경
2.  preview 배포 환경

권장 순서는 아래와 같다.

1.  local에서 기능 단위 확인
2.  preview에서 통합 동작 확인

### 3.3 합격 기준

아래 조건을 만족하면 MVP 기준 통과로 본다.

1.  핵심 사용자 시나리오가 처음부터 끝까지 실패 없이 이어진다.
2.  주요 오류 상황에서 사용자 안내 문구가 나온다.
3.  JWT 보호 페이지와 보호 API가 정상 동작한다.
4.  추천 결과가 지도와 카드 양쪽에 반영된다.

## 4. 테스트 준비 항목

테스트 시작 전 아래 항목을 먼저 확인한다.

### 4.1 환경 변수

1.  NEXT_PUBLIC_SUPABASE_URL
2.  NEXT_PUBLIC_SUPABASE_ANON_KEY
3.  SUPABASE_SERVICE_ROLE_KEY
4.  JWT_SECRET
5.  NEXT_PUBLIC_KAKAO_MAP_APP_KEY
6.  KAKAO_LOCAL_REST_API_KEY

### 4.2 데이터 준비

아래 조건이 준비되어 있어야 한다.

1.  users 테이블 생성 완료
2.  friends 테이블 생성 완료
3.  messages 테이블 생성 완료
4.  테스트용 사용자 2명 이상 생성 가능 상태

### 4.3 외부 연동 준비

1.  Kakao Map JavaScript 키 설정 완료
2.  Kakao Local REST API 키 설정 완료
3.  JavaScript SDK 도메인 등록 완료

## 5. 핵심 사용자 시나리오 통합 테스트

이 항목은 가장 먼저 수행하는 대표 시나리오이다.

### 5.1 시나리오

1.  신규 사용자가 회원가입한다.
2.  메인 화면으로 이동한다.
3.  친구를 추가한다.
4.  친구를 선택한다.
5.  메시지를 전송한다.
6.  위치를 공유한다.
7.  추천 버튼을 누른다.
8.  추천 장소 3개와 지도 마커를 확인한다.

### 5.2 기대 결과

1.  회원가입 성공 후 JWT 쿠키가 설정된다.
2.  메인 화면 접근이 가능하다.
3.  친구 목록에 추가한 친구가 보인다.
4.  채팅 패널이 열린다.
5.  메시지가 목록에 반영된다.
6.  지도에 위치가 표시된다.
7.  중심점과 추천 장소가 표시된다.

## 13. 오류 및 예외 상황 테스트

### 13.1 인증 오류

1.  만료된 JWT로 보호 API 호출
2.  잘못된 JWT 서명으로 보호 API 호출
3.  쿠키 없는 상태에서 /main 접근

기대 결과:

1.  401 또는 시작 화면 이동
2.  사용자 혼란 없이 재로그인 가능 상태 유지

### 13.2 네트워크 및 서버 오류

1.  친구 추가 실패
2.  메시지 저장 실패
3.  위치 저장 실패
4.  추천 API 실패

기대 결과:

1.  화면이 깨지지 않는다.
2.  오류 문구가 사용자 행동 위치 근처에 표시된다.
3.  재시도 가능 상태를 유지한다.

## 16. 배포 전 최종 점검 항목

배포 전에는 아래 항목을 최소한 한 번 더 확인한다.

1.  시작 화면에서 회원가입과 로그인 동작 확인
2.  보호 페이지 이동 규칙 확인
3.  친구 추가와 친구 목록 표시 확인
4.  채팅 저장과 조회 확인
5.  위치 저장과 지도 반영 확인
6.  추천 결과 카드 3개 표시 확인
7.  Kakao Map, Kakao Local API 환경 변수 확인
8.  Supabase 연결 확인
9.  JWT_SECRET 설정 확인
10.  브라우저 콘솔과 서버 로그에 치명적 오류가 없는지 확인
